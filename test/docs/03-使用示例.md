# 使用示例（输入 / 关键输出 / 来源与时间）

> 以下输出均为对本地库的真实只读查询结果。示例只展示数据查询，不构成任何投资建议。

## 示例 1：先盘点某日期的数据可用性（推荐先做）

**输入**
```bash
python3 test/skills/market-calendar-query/run.py query \
  --function data_availability --date 2026-06-01 --pretty
```
**关键输出（节选）**
```json
{
  "status": "ok",
  "data_nature": "historical_snapshot",
  "as_of": { "date": "2026-06-01" },
  "data": [
    { "table": "ohlcv", "rows_on_date": 115,
      "table_min": "2024-01-02", "table_max": "2026-08-12",
      "nearest_date_before": "2026-06-01" },
    { "table": "daily_basic", "rows_on_date": 0,
      "table_min": "2025-12-26", "table_max": "2026-02-09",
      "nearest_date_before": "2026-02-09" },
    { "table": "market_daily", "rows_on_date": 2,
      "nearest_date_before": "2026-06-01" },
    { "table": "moneyflow_dc", "rows_on_date": 5989,
      "nearest_date_before": "2026-06-01" },
    { "table": "dragon_tiger_inst", "rows_on_date": 904,
      "nearest_date_before": "2026-06-01" },
    { "table": "hsgt_individual", "rows_on_date": 0,
```

**来源与时间**：来源为本地各表；`as_of=2026-06-01`。可一眼看出当日估值表无数据、沪深港通已过期。

## 示例 4：无数据（日期早于覆盖区间）

**输入**
```bash
python3 test/skills/market-overview-query/run.py query \
  --function market_breadth --date 2024-01-01
```
**关键输出**
```json
{
  "status": "no_data",
  "data_nature": "not_available",
  "as_of": { "date": "2025-11-05" },
  "data": { "date": "2024-01-01", "up": null, "down": null, "flat": null },
  "limitations": [
    "宽度由 moneyflow_dc(top_n=0) 的 pct_change 逐只统计……覆盖区间约 2025-11-05 ~ 2026-07-08，区间外日期无宽度数据。",
    "该日期无全市场行，可参考的最近日期 2025-11-05。"
  ]
}
```
**来源与时间**：请求日无数据，回退报告最近可参考日期 2025-11-05，**不构造当日结果**。

## 示例 5：数据源失败（数据库文件缺失）

**输入**
```bash
python3 test/skills/market-calendar-query/run.py query \
  --function is_trading_day --date 2026-05-28 \
  --db /tmp/kronos_missing_verify.sqlite
```
**关键输出**
```json
{
  "status": "error",
  "data_nature": "not_available",
  "error": "数据库文件不存在: /tmp/kronos_missing_verify.sqlite"
}
```
**来源与时间**：数据源不可用，明确报错，不返回任何伪造数据。

## 退出码对照

- 示例 1–3：`ok`，退出码 0；
- 示例 4：`no_data`，退出码 3；
- 示例 5：`error`，退出码 3。
