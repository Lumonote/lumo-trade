# 技能包说明与依赖

## 1. 目录结构

```
test/
├── skills/
│   ├── README.md                 # 技能包总览（发现入口）
│   ├── skills.manifest.json      # 机器可读清单
│   ├── verify.py                 # 可复现验证脚本
│   ├── _shared/                  # 共享运行时
│   │   ├── envelope.py           # 标准信封 + 日期/代码归一化 + 合规声明
│   │   ├── db_gateway.py         # 只读 SQLite 网关（?mode=ro）
│   │   ├── handlers.py           # 24 个功能处理器 + 注册表
│   │   └── cli.py                # list/query 子命令、JSON 输出、退出码
│   ├── market-calendar-query/    # 交易日历与数据可用性
│   ├── market-overview-query/    # 市场观察
│   ├── stock-research-query/     # 个股研究
│   ├── capital-flow-query/       # 资金面
│   ├── holders-survey-query/     # 股东/机构调研
│   └── data-provenance-query/    # 来源与时效
└── docs/                         # 本目录
```

每个技能目录固定包含：`run.py`（预置技能名的薄封装）、`SKILL.md`、`references/data-model.md`。

## 2. 运行入口

统一两个子命令：

```bash
# 发现：列出该技能的功能点
python3 <skill>/run.py list

# 查询
python3 <skill>/run.py query --function <fn> [参数...]
```

通用参数：

| 参数 | 说明 |
|---|---|
| `--date` | 查询日期，支持 `YYYY-MM-DD` / `YYYYMMDD` / ISO |
| `--start --end` | 日期区间（区间类功能） |
| `--code` | 个股代码（裸码或带后缀均可） |
| `--limit` | 返回行数上限 |
| `--window` | K线窗口天数 |
| `--db` | 覆盖数据库路径（默认 `data/lumo_data.sqlite`） |
| `--pretty` | 缩进输出 JSON |

## 3. 退出码

| 码 | 含义 |
|---|---|
| 0 | ok / limited（有数据，或受限但已说明） |
| 2 | 用法错误（缺参数/未知功能） |
| 3 | no_data / error（无数据或数据源失败） |

便于在 shell 中分支：`if python3 ...; then ...; fi`。

## 4. 依赖

- **Python**：CPython 3.9+（核心仅用标准库 `sqlite3`、`json`、`argparse`、`datetime`）。
- **无需** pandas / requests / akshare / tushare / numpy。
- 数据库：默认 `data/lumo_data.sqlite`；可通过 `--db` 或环境变量 `KRONOS_SQLITE_PATH` 覆盖。

> 说明：本机默认 `python3` 为 3.14 且无第三方库，技能核心因此刻意只依赖标准库，保证在默认解释器即可运行。

## 5. 安全与只读保证

- 连接以 `file:<path>?mode=ro` 打开，物理只读，不能写入、迁移或触发任何重置；
- 不读取密钥到日志；请求参数回显中不含密钥；
- 验证脚本不删除、不重置任何用户数据；唯一写入是 `test/docs/verification-results.json`。

## 6. 标准响应信封

字段见 `test/skills/README.md`「统一响应信封」。关键状态：

- `ok`：命中数据；
- `limited`：能力受限（如日历未覆盖该日期），已说明；
- `no_data`：该日期无数据，附最近可参考日期；
- `error`：数据源失败（如库文件缺失），附错误说明。
