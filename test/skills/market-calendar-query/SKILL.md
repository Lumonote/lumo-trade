# Market Calendar Query（交易日历与数据可用性）

## 用途

在投研链路中充当“先确认日期、再取数”的入口。它只回答两类事实问题：

1. 某日期是否为 A 股交易日；
2. 某日期在本地各数据表中是否已有数据，以及最近可参考的日期。

本技能**只做查询**，不输出任何买卖建议、目标价、评分或荐股结论。

## 何时使用

- 收到“帮我看 2026-06-01 的数据”这类带日期请求时，先用它确认该日期是否交易日、本地是否有数据；
- 需要确定某个事件日的前/后一个交易日；
- 研究复核前，盘点某日期各来源的覆盖情况，避免把缺失日期当成有数据。

## 功能点（4 个）

| 功能点 | 必需参数 | 说明 |
|---|---|---|
| `is_trading_day` | `--date` | 判定日期是否交易日。命中日历返回 `true/false`；日历未覆盖该日期时返回 `is_open=null` 与日历范围，不臆测。 |
| `list_open_days` | `--start --end` | 列出区间内交易日（升序）。区间超出本地日历时明确标注，不补造。 |
| `nearest_trading_day` | `--date --direction prev\|next` | 求上一个或下一个交易日。 |
| `data_availability` | `--date` | 盘点该日期在各数据表的行数、各表范围与最近可参考日期。 |

## 运行入口

```bash
# 列出全部技能与功能点（发现入口）
python run.py list

# 判定是否交易日
python run.py query --function is_trading_day --date 2026-05-28

# 盘点某日期的数据可用性
python run.py query --function data_availability --date 2026-06-01 --pretty
```

## 数据性质与限制（重要）

- 本地 `trade_calendar` 在本库**只含交易日（is_open=1），不含周末/节假日**。因此：
  - 日期在日历中 → 确定为交易日；
  - 日期不在日历中 → 可能是周末、节假日，也可能是日历尚未覆盖的未来日期，本技能返回 `limited` 与 `is_open=null`，**不会**武断地把“周六”当成“已确认休市”。
- 日历范围（本库）：`2024-03-12 ~ 2026-05-29`。超出范围的日期需由应用联网补齐日历时才能判定。
- 所有结果为本地历史/参考数据，不是实时行情。
