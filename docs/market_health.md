# 大盘体检

桌面入口 `/desktop/market_health`，读取 `/api/market-health`。总览、跨市场研判、板块深度、顶底信号、指数趋势、广度与估值、反转确认、历史对照和指标口径共九个分区。

默认“最新观测/盘中预警”视图优先读取带交易日期和报价时间的当日行情；“收盘确认”保留完整的最新收盘研究快照。首次进入自动启动完整更新，页面可见期间每30秒检查最新指数报价。基线及原始报告随 `config/` 和 `webui/static/` 分发，不依赖开发机的 `results/`。接口失败时明示沿用旧值及其时间。

所有统计的时点表区分实际行情时间、采样日期/区间、上一交易日披露、最新收盘与固定历史研究；生成页面和点击刷新的时间不作为行情日期。指数价格/均线/RSI、市场涨跌/估值、广度、期指基差、每品种席位、两融、量化、资金、反转确认及历史对照均列出输入时点。

价格规则同时保留“当前满足”“当日极值曾触及”“收盘触发”：底部用当日最低价回算价格指标，顶部用最高价。极值假设当日最后一根临时K线价格替换为该高/低价，MA250仍按前249根收盘加该价格计算。极值事件不改写当前或收盘状态，也不意味着反转完成；行情源只提供日高低价时，不推断极值发生分钟。广度、估值、量能及披露数据不能以不同时间、不同股票的最低点拼接。临界差距≤0.5个百分点只作提示，不放宽严格阈值。

## 数据接入

| 维度 | 输入 | 判断依据 |
| --- | --- | --- |
| 指数 | 新浪实时完整报价、腾讯备用报价、现有收盘日线 | 七指数最新价、价格类指标临时计算、价格高低点曾触及；全天量比收盘后判断 |
| 广度 | 新浪市值分层固定样本 | MA20/60/250覆盖、新高新低、250日回撤中位数 |
| 估值 | 全A新浪行情 | 正PB/PE中位数、正PB样本破净率、真实有效分母 |
| 期货 | `futures_service`、前20席位缓存，新增 `fut_daily` / `index_daily` | 净多头持仓增量、主力同一合约相邻交易日真实期现收盘基差变化 |
| 两融 | 现有TuShare客户端 `margin` | 沪深两所完整日融资余额、买入/偿还、净买入及5期余额变化 |
| 量化 | `quant_radar_service`完整按日榜；无历史事件时新增 `daily` / `daily_basic` / `moneyflow_dc` 回填 | 盘口日榜优先；备用收盘行为代理明确标记并按一半可靠度参与，不编造异动次数 |
| 资金 | 现有TuShare客户端 `moneyflow_mkt_dc` | 大盘主力净流入和净占比，金额按官方接口的元处理 |

两融不混加融券余量的股/份/手，不将融券余额直接映射为裸空；期货不将绝对净空头或普通贴水直接当作看空。量化属于公开数据代理识别，沿用现有服务的“疑似”边界。

## 更新与持久化

`POST /api/market-health/refresh` 接受 `indices`、`cross`、`full` 三种模式，返回现有任务队列的202任务响应。分别更新指数、指数与跨市场证据、全部证据及全A行情/广度。运行中重复提交复用任务。

`GET /api/market-health?live=1` 更新/读取30秒缓存的实时指数；`live=force` 跳过缓存。此通道独立于慢任务，顶部刷新会请求实际行情。接口同时返回收盘结果、`intraday`临时结果、`live_status`、逐项`timing`。今日报价超过5分钟未更新时暂停实时判定；午间以11:30、收盘后以15:00判断，避免把正常休市视为延迟。缺少最近收盘历史、报价昨收不匹配或数据来自未来时，不生成今日均线。

收盘快照、盘中采样、实时指数、跨市场结果及任务指针复用SQLite `kv_cache` 的 `market_health` 命名空间。跨市场证据按交易日隔离，盘中结果不覆盖收盘序列。接口失败保留旧值和真实日期；完整广度采集在后台继续。

只有已收盘指数用于全天量比。市场、广度、量化必须与基准日一致；席位、两融及资金允许使用前一实际交易日并减半权重。旧于该窗口及未来数据均排除。

完整更新在盘中也采集当日全A行情与分层广度，不再因未到15:30直接跳过。个股临时日线使用该次全市场报价，记录采集区间；盘中广度不写入连续五日收盘确认。两融、资金和席位按真实披露日展示，今日未披露时明确保留上一交易日，不承诺获得尚不存在的今日最终值。

每次广度采样读取300根真实个股日线，按上证实际交易日回算最近5天。只纳入窗口每天都有收盘、最早一天也已有250根历史的固定成分；整个窗口统一组号和分母。停牌缺日、短历史和失败样本排除；不足200只时保留旧快照。首次即可计算五日确认、新高/新低率与逐项分母，无需等待未来五天。

历史基差以当天成交量最大合约为参照，在前一交易日全部合约中查同一合约；移仓时不拿前一天不同主力相减。所有期货收盘与现货收盘按日期匹配，历史收盘缓存可重复使用。

量化历史无盘口日榜时，通过按日批量接口、分页和股票代码求价量资金同日交集。代理压力=资金净流出个股占比×50%＋放量组（量比≥1.5）中跌幅≥2%且净流出占比≥5%的比例×30%＋收盘位于日内底部25%的比例×20%。有效交集至少200只、放量组至少20只；页面展示各真实分母、公式和降权状态。该代理不还原盘中事件，也不识别交易者身份。

## 综合结论

综合压力权重依次为指数25%、广度15%、估值10%、期指15%、两融10%、量化10%、资金15%。至少65%有效权重、5个有效维度，且期指、两融、量化都可用，才计算综合压力。`complete`只在七维均有效时为真；`sufficient`表示达到最低综合分析门槛。逐项公式和原始证据随API返回。

温度与压力各自表达不同状态，不能混同：低温可能仍有很高去杠杆和下跌压力。底部/顶部特征分别计分，价格反转确认独立计数；综合输出共振、分歧和缺失依据，而非顶底概率。

原报告将创业板−24.78%计作满足≤−25%，本页按未舍入值严格判断。新的12项底部卡以RSI替换原反转项，反转移入独立区，因此计数与原报告不可直接比较。原报告历史回测、日期和目标区间作为固定研究参考保留，不伪装为最新预测。

官方口径：[期货日线](https://tushare.pro/document/2?doc_id=138)、[指数日线](https://tushare.pro/document/2?doc_id=95)、[每日量比](https://tushare.pro/document/2?doc_id=32)、[个股资金流](https://tushare.pro/document/2?doc_id=349)、[两融汇总](https://tushare.pro/document/2?doc_id=58)、[大盘资金](https://tushare.pro/document/2?doc_id=345)。规则为经验设定，未进行顶底预测能力的样本外验证。

## 板块深度

入口 `/desktop/market_health?section=sectors`。行业与概念分别排名，不把地域板块混入主题榜；既展示当日净流入最强，也筛选五日≥4日流入、五日累计净额及相对沪深300收益均为正的持续共振候选。概念成分重叠，板块净额不可加总为全市场资金。

复用现有TuShare配置，新增实际接通 `moneyflow_ind_dc`、`dc_member`、`moneyflow_dc`、`dc_daily` 及沪深300日线、交易日历。按日回补41个交易日完整板块，不以热门Top榜代表全部板块。东财实时接口单独读取并验证f124报价时刻，未返回完整行情则明确采用已披露收盘日；实时观测不覆盖持续性收盘序列。所有金额显示前归一为元：板块资金原生为元，个股资金原生为万元。

每板块研究含3/5/10/20日累计净额、正流入天数、连续流入、五日资金留存、前20%排名驻留、五日名次变化、最近五日相对此前五日的净额加速、稳健MAD异常刻度、复合涨幅与相对沪深300收益。严格对齐实际交易日历：缺日、缺值和重复刷新均不增加连续天数，窗口不完整时不评分。

资金强度=同类型净额百分位与净占比百分位的均值（非正净额记0）；持续性刻度=五日正流入率×40%＋正的五日净额/五日绝对净额和×20%＋前20%排名驻留率×20%＋五日相对收益为正的20分；综合承接强度为两者均值。分数用于描述已经发生的强弱，不是上涨概率，也未进行预测能力回测。

成分穿透使用同日成员去重与同日个股资金，展示覆盖率、净流入成分比例、上涨比例、涨跌中位数、前三只正流入占比、正流入HHI、全部成员资金排序，并可打开现有个股K线与分析。分母按有效记录分别披露；不足90%覆盖时提示样本局限。集中度分母使用全部正流入成员的正净额之和，不除以可能接近0的板块净额。板块实际成交额、换手和前五日均量比来自独立日线，不由净额倒推成交额。

阶段与风险包括持续共振、资金先行观察、单日修复、承接转弱、资金撤退，以及价涨资金流出、五日净流入减速、单日正流入过度集中、20日涨幅过高和成分扩散弱。十日轮动路径与逐日依据可用于核对判断。所有触发条件在代码与界面中明确给出。

接口：`GET /api/market-health/sectors` 只读摘要；`POST /api/market-health/sectors/refresh` 返回共享任务队列202任务；`GET /api/market-health/sectors/detail?code=BKxxxx` 按需读取成分与量价，支持 `refresh=1`。历史、研究和成分穿透缓存使用 `sector_depth` 命名空间，任务运行时重复提交复用任务。已进入板块分区后，顶部完整刷新也会启动板块更新。独立研究导出保留日期、来源与选中板块详细证据。

随源码提供2026-10-23真实研究基线：1,012个行业与概念板块、41个交易日；已验证半导体188/188只、人工智能754/754只同日成分资金。首次可离线查看；其他板块点选后读取现有接口。重建：`PYTHONPATH=. python scripts/build_sector_depth_baseline.py`，读取已有配置，不在源码中存储Token。
