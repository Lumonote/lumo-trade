# 短线作战大屏

全局右上角“短线大屏”按钮在原页面上打开独立全屏工作区。原生Fullscreen API作用于模态窗口内部的容器；浏览器未允许原生全屏时仍铺满应用窗口。“返回”移除大屏并保留原页面表单、滚动与状态。独立地址为`/desktop/short_term`。

## 观察内容

- 板块异动雷达、个股异动、实际涨跌停及连板、资金、盘口事件时间线。
- 中央底部加入涨停、跌停、股票热度和人气快速攀升四个可滚动榜单；核心消息没有有效记录时自动收成82px提示行。涨跌停按实际限价日统计并标注日期，旧收盘数据不会冒充今日盘中数据。人气攀升合并股吧原始人气榜与飙升榜，以源提供的较昨日名次变化为准，显示“昨日排名→当前排名、上升N名”；默认筛选当前前100名、上升至少20名，按当前名次优先，可切换范围和名数门槛。缺少对比数据不推算上涨名次，股价涨幅不参与此榜。各榜单都可检索、完整导出并穿透到股票。
- 四源消息按标题去重，保留多来源和原文入口。核心消息必须具有当日完整日期，并符合重大政策、产业实质变化或公司重大披露条件，排除预测和评论，附筛选依据和观察点。短线快讯按时间排列，排除已入选的核心消息，两栏互不重复。
- 未来45日财经日历、已核验会议基线，以及从带日期和原文的消息中提取的会议预告。官方确认、数据商日程与媒体预告分别标识；过期事件自动退出。
- 中央透视图显示已取得的行业和事件日成分归属。板块与股票之间可互相点选，消息、会议、资金和原始异动均能穿透查看。
- 全量列表可搜索、分页、导出CSV。历史日只读已有归档，缺快照不使用当前数据冒充历史。

界面参照用户截图的近黑背景、冷灰细框、银灰卫星与设备、低饱和分色线束、蓝青信号矩阵和线框工作站。头部只保留一行检索、快照筛选与刷新/全屏/返回；移除大标题、状态时钟、数据来源和导出按钮、三个模式Tab。来源状态可从底部口径明细查看。动效可关闭，尊重减少动效偏好；不依赖生成图片。

3D场景使用本地vendored Three.js r180（MIT，许可证位于webui/static/vendor/three-r180/LICENSE），无需CDN。WebGL不可用时使用Canvas降级场景。

## 接口

- `GET /api/short-term/overview?date=YYYY-MM-DD`：聚合只读数据，省略日期查看最新。
- `GET /api/short-term/section?kind=sectors|stocks|news|core_news|short_news|calendar|limits|limit_up|limit_down|hot_stocks|popularity_rises&q=...&date=...`：完整分区查询。
- `GET /api/short-term/detail?kind=sector|stock|news|event&id=...&date=...`：完整对象及关联记录。
- `POST /api/short-term/refresh`：启动去重后台任务，逐来源报告状态，失败保留原数据与时点。

缓存复用SQLite `kv_cache`的`short_term_screen`命名空间，保存输入、更新时间、后台任务与每日聚合快照，无新增数据库迁移。所有来源独立保留实际日期，刷新时间不替代行情或消息发表时间。关联规则是名称/代码/题材关键词匹配，不推断因果或实际交易者。

财经日历使用TuShare `eco_cal`。源接口可能忽略offset，改用国家×周窗口，并在达到100条上限时继续按日拆分；重复原始记录去重。会议基线包含主办方原文、核验日、时区与验证点，不能把媒体提取结果升级为官方确认。未明确时区的数据不猜测北京时间。
