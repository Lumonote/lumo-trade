# Kronos 算法优化路线图 v26
> 生成时间: 2026-11-21  
> 当前版本: v25 (主力资金 + 期指多空)  
> 目标版本: v26 (筹码结构 + 盘口时序 + 机构行为)

## 📊 当前系统诊断

### 1. 现有优势
- ✅ 双轨统一 (sim/live 共享规则,回测可复现)
- ✅ v25 因子体系完整 (9大维度,30+规则)
- ✅ 风格门控 + 动态阈值 (应对市场环境变化)
- ✅ 回测验证严格 (双半窗检验,单调性约束)

### 2. 已知问题
#### 数据层面
- ⚠️ **因子覆盖率不足**: 回测数据中大量 NaN (sector/quant/tech)
- ⚠️ **数据时效性**: 部分股票 OHLCV 数据陈旧 (停牌/新股)
- ⚠️ **机构数据缺失**: 北向资金/QFII 持仓未接入

#### 算法层面  
- ⚠️ **过度惩罚导向**: 当前规则偏保守,可能错失优质标的
- ⚠️ **时间维度单一**: 只看日线,忽略盘中资金动向
- ⚠️ **筹码结构盲区**: 未考虑换手率/流通盘集中度

#### 性能层面
- ⚠️ **评分通胀**: Top10 中 91% 落在 S 级 (≥85分),分级失去区分度
- ⚠️ **胜率瓶颈**: B+ 级胜率 55.7% 虽已改善,但仍有提升空间

## 🎯 优化方向 v26

### 方向一: 筹码结构因子 🔥 高优先级

**核心逻辑**: 低换手 + 筹码锁定 = 主力控盘良好

#### 新增因子
1. **chip_locked** (筹码集中度 0-100)
   - 计算: `f(近5日换手率均值, 换手率标准差, 流通股本变化)`
   - 理想区间: 换手率 2-8%, 标准差 <1%
   - 预期 IC: > 0.05 (强筹码锁定股票后续涨幅更稳定)

2. **turnover_stability** (换手稳定性 0-100)
   - 避免: 突然放量 (主力出货信号)
   - 避免: 极度缩量 (僵尸股)

#### 数据需求
- ✅ 已有: 成交量/成交额 (可算换手率)
- ❌ 需补: 流通股本历史数据 (Tushare `daily_basic` 表)

#### 评分规则 (暂定,需回测验证)
```python
# 正向奖励
'chip_locked_high_bonus': 5,  # chip_locked >= 80
'turnover_ideal_bonus': 3,    # 换手率在 2-8% 理想区间

# 反向惩罚  
'chip_loose_pen': 8,          # chip_locked < 30 (散户盘)
'turnover_surge_pen': 10,     # 单日换手率 > 15% (异常放量)
```

---

### 方向二: 盘口时序因子 🔥 高优先级

**核心逻辑**: 开盘竞价 + 尾盘资金动向 = 主力意图

#### 新增因子
1. **auction_strength** (竞价强度 %)
   - 定义: `(开盘价 - 昨收) / 昨收 * 100`
   - 理想: 0.5-2% 温和高开 (主动性强但不过度)
   - 警惕: >5% 暴力高开 (可能是诱多)

2. **tail_money_flow** (尾盘资金 万元)
   - 定义: 14:30-15:00 区间净流入
   - 正向: 尾盘拉升 = 主力护盘
   - 负向: 尾盘砸盘 = 主力出逃

3. **intraday_amplitude** (当日振幅 %)
   - 配合使用: 低振幅 + 尾盘流入 = 控盘稳健

#### 数据需求
- ❌ 需补: 分时数据 (1分钟/5分钟级别)
- 备选方案: 只取开盘价 (已有) + 尾盘估算 (用全天资金流*权重)

#### 评分规则
```python
'auction_quality_bonus': 4,   # 竞价强度在 0.5-2%
'tail_inflow_bonus': 6,       # 尾盘净流入 > 500万
'tail_outflow_pen': 10,       # 尾盘净流出 > 1000万
```

---

### 方向三: 量价配合度优化 🟡 中优先级

**问题**: 当前只有 `sell_signals` 计数,未评估量价关系质量

#### 改进点
1. **volume_quality** (量价配合度 0-100)
   - 健康: 上涨放量 + 下跌缩量
   - 警告: 价涨量缩 (背离信号)
   - 危险: 下跌放量 (恐慌盘)

2. **volume_surge_risk** (异常放量风险 0-100)
   - 单日量比 > 3.0 且非持续性 = 脉冲出货

#### 数据需求
- ✅ 已有: 成交量数据
- 需计算: 20日均量,近5日高量天数

#### 评分规则
```python
'volume_quality_bonus': 5,    # 量价配合 >= 70
'volume_divergence_pen': 12,  # 价涨量缩 (quality < 35)
'volume_panic_pen': 15,       # 下跌放量 (surge_risk > 80)
```

### 方向四: 机构行为追踪 🟡 中优先级

**核心逻辑**: 跟踪聪明钱 (北向资金 + 机构龙虎榜)

#### 新增因子
1. **smart_money_signal** (-100 to 100)
   - 北向资金 5日持仓变化
   - 龙虎榜机构席位净买入
   - 组合成方向性信号

2. **inst_interest** (机构关注度 0-100)
   - 龙虎榜机构席位数
   - QFII 持股家数
   - 非方向性,纯关注度

#### 数据需求
- ✅ 已有: 龙虎榜数据 (部分)
- ❌ 需补: 北向资金持仓 (Tushare `hk_hold` / 东财接口)
- ❌ 需补: QFII 持股 (Tushare `stk_holdertrade`)

#### 评分规则
```python
'smart_money_inflow_bonus': 8,  # smart_money_signal > 50
'inst_interest_bonus': 3,       # inst_interest > 70 (加分但不过度依赖)
'inst_flee_pen': 12,            # smart_money_signal < -60 (机构集体撤离)
```

---

### 方向五: 相对强度体系 🟢 低优先级 (长期)

**核心逻辑**: 个股 vs 板块/大盘的独立性

#### 新增因子
**relative_strength** (相对强度)
- 定义: `个股5日涨幅 - 板块5日涨幅`
- 强势特征: 大盘跌它抗跌,大盘涨它更强
- 配合 RSI: 强势股调整到位 = 低吸机会

#### 应用场景
- 大盘下跌时: 筛选相对强度 > 5% 的抗跌股
- 板块过热时: 筛选相对强度 < -10% 的落后补涨股

#### 评分规则
```python
'relative_strength_bonus': 6,      # 相对强度 > 8% 且 RSI < 50
'divergence_opportunity': 5,       # 强势股回调 (强度>5%, chase<30)
```

## 🔬 验证标准

### 回测要求 (v26 上线前必须通过)
1. **样本量**: >= 500 条 (至少 50 个交易日)
2. **IC 检验**: 新因子 Spearman IC > 0.03
3. **双半窗一致性**: 前半窗/后半窗方向相同
4. **单调性**: 分层回测 5 分位,高低分组收益差 > 2%
5. **相关性**: 与现有因子 Pearson 相关 < 0.6 (避免冗余)

### 性能目标
- B+ 胜率: 55.7% → **58%+** (提升 2.3 pct)
- 平均收益: +2.30% → **+3.0%+** (5日)
- 评分区分度: S级占比 91% → **< 30%** (动态阈值生效)

## ⚠️ 风险提示

### 数据风险
1. **北向资金延迟**: 通常 T+1 公布,实时性不如日内资金流
2. **分时数据成本**: 如需高频数据,可能触及接口限流
3. **新股数据缺失**: 上市不足 30 天的股票因子覆盖率低

### 过拟合风险
1. **因子过多**: 当前 v25 已有 30+ 规则,v26 再加 10+ 易过拟合
2. **回测窗口**: 164 交易日对复杂模型仍然偏短
3. **市场环境变化**: 2025-11~2026-07 经历了小盘崩盘,样本偏向防御

### 缓解措施
- 新因子必须通过双半窗检验 (前后半窗方向一致)
- 优先选择物理意义清晰的因子 (可解释性)
- 保留 v25 作为 baseline,v26 增量慎重
- 定期(每季度)用滚动窗口重新验证

## 📚 参考文献

### 学术依据
1. **筹码集中度**: Barber & Odean (2008) "All That Glitters" — 低换手率股票长期收益更高
2. **盘口时序**: Admati & Pfleiderer (1988) "A Theory of Intraday Patterns" — 开盘/收盘时段信息含量更高
3. **量价关系**: Karpoff (1987) "The Relation Between Price Changes and Trading Volume" — 量价背离预测反转
4. **机构行为**: Gompers & Metrick (2001) "Institutional Investors and Equity Prices" — 机构持股与股价稳定性正相关

### 业界实践
- 聚宽因子库: 换手率因子 (TVMA20) IC ≈ 0.06
- 优矿平台: 竞价强度因子 (AUCTION_STRENGTH) 月度 IC ≈ 0.04
- 米筐 RQData: 主力资金因子已验证有效 (v25 已接入)
